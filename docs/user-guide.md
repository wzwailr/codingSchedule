# codingSchedule 使用说明

当前是 Windows x64 **未签名内部候选版**，可选择 WebView2 安装版、Electron 安装版或 Electron 便携版。安装不要求系统 Node，开机启动默认关闭。安装器默认勾选 Codex / Claude 自动接入，可取消。完整宿主、原生输入与性能验收见 [验收记录](verification/acceptance.md)和 [WebView2 验收记录](verification/webview2-migration.md)。

1. WebView2 版运行 `codingSchedule-WebView2-0.1.0-setup.exe`，安装器会检测系统运行时，缺失时通过微软引导程序联网补装。Electron 安装版运行对应的 `setup.exe`，便携版完整解压 ZIP 后运行 `codingSchedule.exe`。`resources` 中包含程序运行所需的脚本与许可，请保留整个程序目录。
2. 普通启动默认检测 Codex / Claude 的已知日志目录；托盘 → 接入 / 设置可以关闭来源或修改路径，原始日志只读。窄OLED显示身份、计划和时间；点击或悬停展开详情翼，移开延迟收起。可拖动整块OLED移动；“固定展开”保持详情，“−”或再次点击OLED手动收起。靠近右边缘会向左展开，保持状态屏位置。键盘操作可从托盘“展开并聚焦”进入，用Tab选择控件，OLED上Enter／Space切换，Escape取消固定并收起。[双翼折屏验证](verification/fold-window.md)。

如果悬浮框被隐藏或覆盖，再次运行同一程序即可恢复显示和置顶，不会新开第二个悬浮框；也可用托盘“显示悬浮框”。

两态均有尺寸角标，默认100%，范围35%–200%，受当前工作区限制。75%及以上完整展示；50%–74%隐藏长身份与次要说明；35%–49%只留简短状态、进度和短ETA，最小约68×92 DIP。小尺寸不把完整布局缩成小字；点击／悬停仍展开可读的详情翼，收起准确回到所选尺寸。角标聚焦后方向键每次调整5%，Home恢复100%，拖动时Esc取消。OLED上滚提高不透明度、下滚降低，每次5个百分点，范围40%–100%；详情、列表和设置正常滚动。设置顶部可输入尺寸、调不透明度或“恢复默认外观”，托盘也有恢复入口。提交后自动保存，重启保留。短ETA如“2–4分”保留区间并向外取整，精确倒计时和完整身份见展开／提示；未知、超时、等待与完成分别表达。[三档验证](verification/density.md)；[v25外观基线](verification/appearance.md)。

3. 安装版保持默认“配置 Codex 和 Claude Code”即可同时安装两宿主 MCP、Skill、默认汇报规则与异步估时 Hook。便携版或此前跳过的用户，进入“接入 / 设置”，点击顶部“一键配置 Codex 与 Claude”；不必逐项复制文件或填写标准目录。支持检查、缺失修复和整体撤销，其他配置先备份并保留。请在方便时重新连接或重开 AI 宿主，开始新任务确认实际汇报；程序不会打断正在进行的任务。高级逐项入口仍保留。见[一键接入验证与 token 测量](verification/one-click-setup.md)和[接入说明](integrations.md)。不能保证宿主隐藏工具卡，Skill 也不能强制模型每次调用。
4. 普通启动自动检测本机 Codex / Claude Code 日志，来源可在设置中关闭；隔离 `--data-dir` 模式需显式开启来源。列表只展示活动会话，每个 session 仅保留最新轮次，标签为“项目名称 · session名称”，不显示编号；缺元数据时显示“未知项目”或“未命名会话”。Claude Code 的子 agent 日志不单列为主会话。原生观察与agent上报按公开任务引用自动归并；已结束、暂停、闲置历史不进入下拉框。默认跟随最近活动，手选会话后可点击“自动跟随”；选中的会话结束后自动切换，没有活动则显示空态。近期活动窗口为三分钟，尚未返回的工具调用继续保留；源日志缺失或宿主崩溃可能使判断不完整。
5. 收起时显示会话、进度和粗估时间；悬停查看当前动作。从未收到可靠计划时进度未知；已有进度与估时后，显示百分比按估时上下界与经过的活跃时间自行增长，最多99%，直至agent明确收尾；原计划步骤仍独立保留。下一次省略进度或时间、时间返回null都不清空最近有效数据；新有效估时立即校正倒计时。等待/暂停冻结，到零显示超时，不自动完成。新agent估时的区间跨度最多十分钟，无法合理缩窄时保留上次计时，其他进度照常提交；历史或步骤先验的宽区间改为显示“约”一个剩余时间，保留原上下界用于内部计时，不伪造更窄的置信区间。模型仅在首次可估或必要修正时报告时间。AI报告完成仍与人工验收不同。[可靠汇报与贴边隐藏](verification/reporting-reliability.md)。
6. 设置中的“登录 Windows 时启动”默认为关，可显式开启并随时关闭。开发和自定义 `--data-dir` 隔离模式禁用此开关。移动便携目录前先关闭，移后重新开启。
7. 退出请用托盘 → 退出，后台采集器随之关闭。采集器断开时显示状态提示，可在设置或托盘重新连接。

展开详情后，在“正在做／当前动作”右侧切换 **工作事项** 和 **执行状态**。工作事项显示AI主动汇报的具体工作，执行状态显示会话观察到的工具调用、分析等动作；下方分别标明来源和更新时间。某类数据缺失时明确提示，不拿另一类冒充。切换不改变会话、计划、进度或倒计时，选择会自动保存并在下次启动恢复；默认保持工作事项。[双视角验证](verification/activity-views.md)。

一键接入会沿用可确认兼容的旧 MCP、Hook、默认汇报规则和相同 Skill，不因程序路径或规则版本不同直接报冲突。仅缺失项会补齐，禁用配置、未知同名内容或其他凭据路由仍保留并提示核对。手动关联已移入默认收起的“高级设置”，只在自动关联失败时使用；两侧只列当前活动项，结束、暂停或过期后自动移除，无可选项时禁用按钮。见[兼容与活动关联验证](verification/setup-compatibility.md)。

运行时无需选择监测哪个 AI：普通启动同时检测 Codex 和 Claude 的已开启来源，活动会话自动出现和跟随。设置顶部显示两来源的实际开启状态；手动配置目标、日志路径与监测开关均在“高级设置”中。切换“配置目标”仅用于维护接入文件，不切换监测对象。用户明确关闭的来源保持关闭，见[自动监测设置验证](verification/automatic-monitor.md)。

## 升级与数据

新版Windows MCP由轻量原生入口持有连接生命周期，工具描述与协议版本从官方SDK生成，业务仍通过已有鉴权和校验。后台暂不可达时返回工具错误，后台恢复后同一连接的下一次自然汇报可恢复，不自动重放不确定写入。旧转发器和已经关闭的宿主连接需要在安全点换到新版并重新连接一次；程序不强行重启AI宿主。Node MCP／CLI仍保留。

靠近工作区四边约24DIP内，鼠标离开约800ms后自动隐藏为墨玉环扣；悬停或点击恢复。固定展开、设置、拖动和缩放期间不自动隐藏。托盘“显示悬浮框”、重新运行程序可恢复；“展开并聚焦”可进入键盘操作。设置顶部可关闭“靠近屏幕边缘时自动隐藏”。偏好独立保存，保留原尺寸、不透明度和OLED锚点。左右为32×64 DIP，顶部/底部为64×40 DIP，以匹配本机Windows实际外框与胶囊点击区域。

退出旧版本再覆盖便携目录，或安装新版本到同一目录。Windows 应用数据默认在 `%USERPROFILE%\.coding-schedule`，避免不同 AI 宿主对 AppData 的重定向造成进度和凭据分离。首次从旧版升级会校验并迁移原目录的一致性快照、设置和接入回执，旧目录保留；旧程序仍运行、目标配置冲突或校验失败时会停止迁移，不会清空数据库“修复”。数据库版本升级前仍先保存快照至当前目录的 `backups`，再执行迁移事务；备份不会自动删除，清理前先核对。

不要在旧程序中打开新版本数据库。需要回退时先退出应用，另行备份整个数据目录，再恢复 `backups` 内的旧数据库；故障现场保留用于排查。配置补丁旁的 `.codingSchedule-*.bak` 是宿主原配置备份，可能包含私人设置，请按私人文件保管。

## 卸载

安装版通过 Windows“已安装的应用”卸载。WebView2 卸载回退本版接管的配置，保留进度库与迁移备份。Electron 卸载界面默认勾选**保留进度数据库与迁移备份**，取消后只删除本工具固定数据库文件和具名迁移备份。接入条目按安装回执撤销；条目已被其他程序修改时会停止卸载，请先在设置逐项撤销或人工核对。更新安装保留接入和进度。

便携版：退出后先在设置撤销每项接入并关闭登录启动，再删除已解压的程序目录。也可以在程序退出后，通过临时设置 `ELECTRON_RUN_AS_NODE=1`，运行 `codingSchedule.exe resources/integration/remove-cli.cjs --data-dir <绝对数据目录>` 做接入撤销，结束后清除该变量再启动 GUI；默认保留进度，只有显式添加 `--delete-progress` 才删除固定进度文件。配置冲突会退出非零，应先解决冲突，再删除程序。旧版本接入仍引用旧目录时，应先在设置检查/修复并在方便时重连宿主，再清理旧程序目录。

默认保留本地设置、连接凭据、Chromium 缓存和宿主配置备份，避免粗暴递归清理。它们不等于原始 AI 会话日志；不再使用时可在核对后自行处理。不要把私人数据目录和凭据上传到仓库。
