# 悬浮窗紧凑进度条改版

用户选择：2026-10-27「按紧凑进度条直接实施」，授权自行细化和验证。阶段五继续；改版前的采样独立留作基线，不作为新版性能结果。

## 方案与边界

采用紧凑进度条：保留收起 320×48、展开宽 360 / 高≤420 DIP，250ms 悬停、400ms 离开、固定和不抢焦点规则。另一方案是增加高度常驻显示动作的双行信息条，代价是占用更多桌面；用户未选择。任务、计划、完成和 ETA 的领域定义不变。

沿用原生 HTML/CSS/TypeScript，不增加 React、antd、字体或图标依赖。Ant Design 的字体、对比、反馈规范用于信息层级与状态表达；不是声称使用了 antd 组件。技能内反馈文档标记 `skip: true`，仅作为参考。参考包为固定快照，不依赖当前外部 API。

## 信息结构

- 收起：第一行任务名，第二行工具、计划进度、粗估剩余时间；多任务数和拖动区保留。完整内容有文字提示，长标题省略。底部细进度线与文字来自同一快照；未知不填充。
- 展开：来源与文字状态 → 任务名 → 当前动作 → 计划进度和 ETA → 步骤。底部保留任务切换与接入设置，内容过长在中间滚动，操作可达。
- 主色采用蓝色，文本和边界用中性灰；成功、等待、错误辅以文字及符号，不能只靠颜色区分。AI 报告完成仍需人工验收，不显示成已验收。
- 无任务显示接入引导；无计划显示未知解释；等待、暂停、过期、超出估计和断连均沿用真实状态，不生成虚假百分比或计时。
- 浅/深主题，系统字体；正文 14px、辅助 12px、标题 16px，数值等宽。减少动效设置关闭过渡，无持续动画、模糊或 GPU 特效。

## 验证与限制

真实 Electron 检查长中文、无计划、等待、完成待验收、过期与断连；收起与展开、固定、任务切换、设置、键盘焦点、浅深主题。新界面重跑桌面回归、包内 MCP 和原生 hover。阶段五负载与资源门槛保持不变；旧版 CPU/内存不能推定新版结果。当前显示环境只能提供单屏 100% DPI 证据，不能代替 IME / 多屏 / 物理 DPI。

设计依据：本机 `ant-design-ux` 的 `design-patterns.md`、`ux-collaboration.md`，以及原始 `font.zh-CN.md`、`contrast.zh-CN.md`、`feedback.zh-CN.md`。既有实现与测试确认窗口几何、事件权限和快照字段后再改动。
