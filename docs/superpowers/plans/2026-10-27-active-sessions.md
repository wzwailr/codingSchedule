# 自动发现活动会话实施计划

目标：无需每个聊天主动报告即可发现 Codex / Claude 的当前工作；悬浮框只显示活动会话，不展示历史轮次。

已核实：实际来源已开启；107 条记录中有102条旧暂停轮次；renderer 将所有快照放入下拉框，自动选择长期保留旧项；新文件发现默认30秒。沿用 Electron / TypeScript / SQLite，不引入框架或额外模型。

执行判定：沿用用户对本产品“细节由你确定、直接实施”的授权。活动指未结束且三分钟内有真实日志活动，或存在尚未返回的工具调用；日志缺失不能解释为已完成。先按 session 合并最新轮次，再过滤空闲与终态，避免旧轮次复活。等待/阻塞在近期仍可见。没有活动时显示空态。未知计划与估时保持未知。日志自动发现不自动修改宿主 MCP/Hook 配置。
