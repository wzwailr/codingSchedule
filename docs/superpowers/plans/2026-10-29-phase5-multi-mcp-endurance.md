# 阶段五：多 MCP 内存与耐久中断修复

目标：维持220MiB预算，测量3个同时连接的MCP实例；修复可复现的回放端口缓存/瞬时断连问题，再执行最终包标准负载并启动真实八小时耐久。保留既有v7改动、用户日志/数据库与宿主配置。

证据：现有桌面进程加3个Node MCP约265.6MiB；隔离单实例完整SDK44.16MiB、SDK低层39.79MiB、裸Node22.57MiB，软GC参数已使用，不能靠重复参数消除运行时基座。旧长测3小时43分fetch failed、0应用崩溃，未保留cause，不能追认唯一历史根因；真实采集器重启已复现驱动缓存旧端口后ECONNREFUSED。
