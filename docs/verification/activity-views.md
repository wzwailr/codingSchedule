# 工作事项与执行状态双视角

2026-11-02，本地v38目录包。沿用双翼和墨玉环扣，增加“正在做／当前动作”区域的双视角切换。未引入新UI库、额外模型调用、宿主配置修改或耐久测试。

## 数据和交互

- **工作事项**：显示AI主动汇报的具体工作，来自reporter activity；不会被后续工具调用覆盖。没有汇报时显示“尚未收到具体工作事项”。
- **执行状态**：显示当前已归并会话的观察动作，优先读取`nativeActivity.action`；纯原生会话沿用自身activity。只有真实in-flight证据但无具体动作时显示“工具执行中”；没有观察证据时明确显示“尚未检测到执行状态”。不展示或猜测隐藏思维内容。
- 两类来源共存于同一活动会话，不新建重复任务。下方分别显示“AI汇报／会话观察”和对应更新时间，来源缺失不静默换成另一类内容。
- 两个原生按钮以`aria-pressed`表达选择，键盘Enter/Space可切换。选择保存在共享数据目录`view.json`，默认work，支持重启恢复，非法文件内容回退默认。保存失败保留上一次选择并提示重试，快速连续操作按顺序保存。
- 切换只改变展示与独立偏好，不修改快照、进度、步骤、ETA、会话选择或agent状态。既有持续倒计时、等待冻结、环扣与收起/展开保持原规则；未新增数据库迁移。
