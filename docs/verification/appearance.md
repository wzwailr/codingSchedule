# 双翼等比缩放与整窗不透明度

2026-10-30，Windows 11、Electron45、本机单屏1920×1080／工作区1920×1032、100%系统缩放。v25本地目录包已启用：`release/appearance-candidate-v25/win-unpacked`。只做本地实现与验证，没有推送、公开发布或生成新的ZIP／NSIS；耐久保持用户取消。

## 实现与使用

- 收起和展开都有独立尺寸角标，整体等比缩放90%–200%，包含文字、圆角、铰链和按钮。两态共享比例，以OLED中心为锚点，按展开所需工作区限制实际大小，靠右可向左展开。拖动整块OLED移动与角标调整大小互不替代。
- 指针捕获期间实时预览，松手才保存；快速末次坐标保留，Esc、pointercancel和丢失捕获恢复原值。调整期间抑制悬停折展，结束后继续原有固定、离开收起和手动收起行为。角标可Tab聚焦，方向键5%微调、Home恢复100%。
- OLED上滚提高、下滚降低整窗不透明度，40%–100%，每次5个百分点。小增量累计、80ms最小间隔、单事件最多一步；像素／行／页模式归一化。详情、计划列表和设置的滚动保持原用途；Ctrl／Meta滚轮不改外观。
- 设置顶部提供尺寸数值、加减按钮、不透明度滑杆、恢复默认外观；托盘也可恢复。默认尺寸100%、不透明度100%，配置单独原子写入`appearance.json`，来源设置不会覆盖它。旧配置、类型错误、非有限数或损坏文件安全回退／限幅。
- 保留真实数据、持续倒计时、等待冻结、100%收尾仍显示有效ETA、活动会话归并、项目／会话名、Claude兼容和既有输入焦点策略。没有新增React、AntD、动效库或演示业务数据。
