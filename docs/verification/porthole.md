# 时光舷窗展示与主题预览

2026-11-09，本地实现与验证；未推送或更新 GitHub Release，耐久测试未启动。

## 已实现

在已有双翼左屏内应用用户选中的“时间舷窗”，功能名称采用用户最新表述“时光舷窗”。圆环使用现有 `displayedProgress` 的真实展示值，圆心读取现有 `screenEta`，不生成新进度或 ETA。无可靠进度时显示虚线空轨；有效 ETA 仍独立显示。区间分两行排版，完整文本及可访问名称保留。等待、超时、AI 完成与人工验收仍使用既有状态语义。较长的完成提示和小时读数采用适配字号。

普通密度显示舷窗；紧凑和微型密度保留数字、直线进度和短 ETA。窗口几何、原生命中轮廓、缩放阈值、贴边环扣、焦点策略、会话筛选与 Codex/Claude 接入均沿用现有实现。原来的紧凑进度条继续用于紧凑密度。

“暖纸便签 / 极简悬岛 / 像素终端”是另行提供的三个完整视觉世界预览，分别采用纸笺、横向胶囊和终端机身；它们尚未替换生产主题。预览中的项目、会话、动作、进度与时间均为示例数据。

## 验证

- TypeScript、ESLint、Electron 构建和 WebView2 构建通过。
- 8 个相关测试文件共 25 项通过，覆盖折展、锚点、固定、键盘、密度阈值、工作事项/执行状态、贴边环扣、估时保留与进度推算。新增舷窗测试在最后的文案适配后单独复跑通过。倒计时断言使用有界等待，避免跨秒取整和渲染周期造成偶发失败。
- 新增测试覆盖进度未知而 ETA 有效、计划 100% 时倒计时继续、暂停冻结、终态中文、超时，以及 35% / 50% / 75% / 100% / 150% 尺寸。浅深两态截图保存于 `.artifacts/porthole/`。
- 三套独立预览各检查 11 种状态、折展、贴边恢复、动作视角和 Codex/Claude 标识；736px / 390px / 320px 无横向溢出，浏览器未记录脚本错误。证据在 `.artifacts/progress-designs/theme-check.json`。
- 新 WebView2 试用载荷以独立数据目录启动，本机 HTTP/SQLite 接受合成验收任务，返回 200。真实可见窗口为 148×272，中心命中属于本窗口；限定窗口范围的桌面截图确认舷窗、实际进度和倒计时已渲染。采集截图没有发送输入，前台窗口未改变。证据为 `.artifacts/porthole/native-proof.json` 和 `native-collapsed.png`。验收窗口随后关闭。
- Impeccable 检测对预览未报问题；现有应用仍有小字号警告，包括旧页脚和详情次要文本。本次没有扩大修改整个详情和设置界面。

## 边界

WebView2 物理鼠标拖动、透明区实点、折展/贴边恢复与键盘焦点未在本轮重新实测。现有工具的窗口枚举未列出该原生工具窗口，因此本轮使用限定窗口范围的桌面截图检查渲染。Electron 的自动化交互通过不能代替 WebView2 原生交互验收。实体高 DPI、多屏和干净 Windows 环境未补验；既有资源预算与耐久未重新测量。
