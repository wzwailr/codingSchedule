# 墨玉环扣贴边收起态

2026-11-02。本地v37目录包，沿用用户选定的“墨玉环扣”，保留双翼展开态、活动会话归并、进度和ETA领域逻辑。耐久保持取消，未推送、未发布。

## 改动

- 深石墨胶囊、冰蓝细进度环和方向图标替代旧蓝色方条。数字采用11px等宽数字，颜色与原OLED协调；不依赖React、AntD或动效库，未复制原型的轮播、Tweak或示例数据。
- 接入原`displayedProgress`，不制造新百分比。未知进度显示横线，正在运行且计划未知采用静态断续环；零进度不画假起点。等待、暂停和阻塞保留数字，以暂停图标辅助表达；完成和失败用独立符号，实报100%且仍运行时保留数字及有效估时。
- ETA仍使用既有倒计时和冻结逻辑；悬停描述、可访问名称持续带上会话、状态、进度和ETA。收起态无需塞入难读的时间小字，恢复后继续显示完整时间。没有增加定时模型调用。
- 侧边保持32×64 DIP。实测Windows把32px高横向窗口撑到39px，故顶部/底部采用64×40 DIP；CSS胶囊和Win32输入区域一致，位置按真实尺寸约束在工作区内。
- 原生裁剪移除透明圆角，光标恢复检查也复用相同区域；透明角落不会因矩形包围盒而误触恢复。既有悬停/点击恢复、离开延迟隐藏、固定展开和设置退出规则继续沿用。减少动态效果时关闭环扣过渡。
- 清理了被替代的方条CSS和Unicode箭头；未修改进度/ETA领域、数据库结构、MCP接入或宿主权限。

设计依据：Ant Design UX本地规范的“对比/主次与状态关系”“图标/准确和简单”“动效/高效、克制”；Impeccable的Operate与polish流程。数字、原生命中和计时以项目实测为准。
