# 自动收起、原生裁剪与小圆盘

2026-11-09，本地修复候选 `release/interaction-v2`。未推送、未发布，耐久没有启动。

## 修复内容

1. **详情移开后不收起**：原逻辑只在鼠标状态改变时创建收起计时，且部分取消操作保留了旧计时器标记。统一取消与清空，窗口已展开但鼠标已在外部时也能补上收起计时。按实际显示区域判断外部，透明角落不再当成整个矩形窗口内部。固定、设置、拖动与缩放期间继续保护。
2. **最小圆盘反复弹回**：原生小窗口改变布局后，WebView2可能根据旧鼠标点生成进入事件。隔离载荷记录到原生鼠标在外部、DOM却反复进入并展开。延迟动作执行前再次核对原生鼠标位置，抑制这类过期事件；正常真实悬停仍可展开。取消冗余折展，避免重置贴边隐藏期限。
3. **边缘锯齿**：原生二值裁剪曾直接压到CSS轮廓，圆角每90度只有8段近似。改为32段，并保留1DIP平滑边缘。边角和大块透明空白仍在原生命中区域之外。区域检查后，桌面解锁补齐了边框和圆盘的真实像素复核，见后补记录。
4. **缩小变矩形**：圆盘不再复用矩形微型尺寸，35%–74%使用圆形尺寸，最小状态屏80×80 DIP，外框92×92 DIP。各档半径为直径的一半；小尺寸改为圆环、短状态、百分比与短ETA，底部保留尺寸入口。其他三主题密度保持原有规则。
