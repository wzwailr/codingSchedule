## 本次检查

- 类型检查、lint、文档本地链接与第三方来源检查通过，Electron开发载荷和WebView2安装包构建通过。
- 首轮非耐久回归：227项通过、3项失败、9项跳过。两个窗口用例只操作CDP虚拟鼠标，没有同步Win32光标；密度用例沿用了旧字号的20DIP高度断言，新外观在75%正常档的25px行高为18.75DIP。

## 当前版本安装与窗口

0.1.1隔离安装使用含中文/空格的路径与受限PATH，保留已有宿主配置。安装8个接入组件，Codex和Claude各自通过真实stdio调用四个MCP工具、提交动作与ETA；原生窗口置顶、透明角落区域排除、窗口中心命中及不抢前台焦点检查通过。干净退出、重复安装和卸载回退通过，进度库保留。此处的两provider客户端不代表重新调用了真实Claude模型。

正式安装载荷与关闭注册表/快捷方式写入的隔离测试安装载荷，47个文件逐一SHA-256一致。当前渲染器、原生窗口入口与WebView2主控制器载荷，也与此前已取得原生像素的`interaction-v2`逐文件一致；仅版本相关后台构建与发行材料更新。像素与交互的具体范围见[窗口交互记录](window-interaction.md)，四主题截图见[主题记录](themes.md)。

测试结束后复查项目Electron、测试runner与隔离WebView进程；临时配置、数据库、原生桌面截图和日志位于忽略目录，不进入公开源码。公开截图只使用隔离合成数据。
