# 汇报连接、连续进度与贴边隐藏

2026-10-30，本轮本地实现与有限验收。日常运行包为 `release/reliability-final-v36/win-unpacked`。核心实现、打包启用与标准资源门禁已完成，最后一轮原生输入检查和扩大真实宿主样本仍待验；不能据此关闭阶段五或整个可靠性计划。耐久保持用户取消，未推送、未发布。

## 本轮改变

- Windows原生MCP入口独立维持stdio生命周期：后台离线可握手和列工具，调用返回可恢复错误；后续自然调用重读endpoint/凭据。没有后台自动重放写入。工具描述、schema、支持协议版本来自官方SDK生成的构建头；业务沿用HTTP校验。移除被替代的共享管道服务及其专用夹具，保留Node SDK/CLI入口。
- 降级报告通过精确绑定回执与原生日志归并。回执只储存散列，有效十分钟，最多512条，绑定原任务、connector/provider/session/turn和实际item/call；失败、伪造、过期、跨调用或跨会话的副本无效。未按cwd/标题/最近任务猜测绑定，未改宿主权限。
- 原始计划进度与显示进度分别保存。后者使用最近有效估时上下界计算两个时间比例的平均值，在缺少新报告时增长，最多99%；不添加额外标签。等待/阻塞/暂停冻结；明确实报100%仍保留有效ETA，AI finish与人工验收分开。
- null/省略ETA和后续不完整计划不清除最近有效数据；新有效估时重设锚点，不因普通报告刷新同一个旧估时。新agent ETA区间跨度超过600秒只产生`ETA_RANGE_TOO_WIDE`警告，同批其他动作/进度照常COMMIT，旧倒计时保留。原步骤先验/历史宽区间不伪造缩窄；短屏的窄小时区间用分钟显示，避免90–100分钟被放大成1–2小时。
- 已精确绑定且最新原生轮次仍运行的活动、等待和阻塞任务，不再仅因三分钟无语义报告消失；等待值仍冻结，最新原生轮次停止仍移出。宿主崩溃无停止记录的日志限制继续存在。具体agent动作不被通用“执行命令”覆盖；详情另记AI汇报时间。
- 后台重启只给正在运行的reporter标记恢复性暂停。原reporter下一次有意义的动作、步骤或计划报告可自然恢复，扣除离线间隔；context、纯ETA和原生观察不恢复它，人工暂停和明确等待也不自动恢复。当前原任务已实际验证普通动作报告使`paused → active`且保留有效估时。
- 四边贴近工作区约24DIP内，离开约800ms后藏为32px短签。几何锚点与隐藏窗口分开，固定/设置/拖动/缩放期间不隐藏；悬停、点击、托盘或重复运行可恢复，设置可持久关闭。短签宽或高为32px，匹配Windows最小外框与点击范围。真实光标检查修正捕获/裁剪后DOM悬停状态残留，不扩大原生输入区域或主动聚焦。未引入框架、动效库或额外模型调用。
- 同步Codex与Claude已安装的coding-schedule-report：开始、阶段结果、动作改变、等待恢复、完成五类触发，压缩上下文保留私有handle；不轮询ETA，不启动竞争任务，错误时继续主任务。

## 当前边界

旧版当前聊天的已关闭MCP transport不能由替换二进制复活。当前任务经实际宿主注册配置启动的新SDK连接成功报告并精确归并；这不等于当前聊天缓存的原生工具目录已重连。旧入口仍需在自然安全点重新连接，未为此重启Codex或Claude。

本轮没有重跑最新包的真实Claude桌面自然汇报；协议、解析和provider兼容回归通过，历史v22真实Claude成功不能冒充本轮成功。Skill不能保证所有模型遵从，单次长思考/长工具内部不能保证即时语义汇报。

物理高DPI、多屏、IME，以及可选轻量checkpoint、限次异步提醒、每宿主30条自然任务样本仍为未验证或后续范围。最后原生组合检查仍待用户空闲，不标记完成。下界为零的时间增长防跳变、旧宽区间近似显示及十分钟区间分钟舍入有单独边界回归。
